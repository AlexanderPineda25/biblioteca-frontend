# Frontend technologies

## Runtime

- React 19.
- Vite.
- React Router.
- Axios.
- Tailwind CSS.
- Lucide React para iconos.

## Production serving

- Nginx `stable-alpine`.
- SPA fallback en `nginx.conf`.
- Imagen multi-stage en Dockerfile.

## Integrations

- `identity-service` para login, registro y JWT.
- `catalog-service` para catalogo y recomendador IA.
- `chatbot-service` para ventana flotante IA.

## Delivery

- Dockerfile propio.
- Kubernetes Deployment, Service e Ingress propios.
- GitHub Actions independiente.
- Azure Container Registry.
- Azure Kubernetes Service.
